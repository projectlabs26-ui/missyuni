📄 Konversi Panduan ke PDF

💡 Cara Menggunakan:

Buka file panduan (PANDUAN-ADMIN.md atau PANDUAN-SISWA.md) dengan salah satu cara di bawah, lalu simpan sebagai PDF.

🎯 Cara 1: Online Converter (Paling Mudah)

1 Buka browser, kunjungi salah satu website ini:
  • Markdown to PDF
  • MD to PDF
  • Pandoc Online
2 Buka file panduan dengan Notepad/Text Editor, lalu copy semua isi file.
3 Paste ke website converter tadi.
4 Klik tombol "Convert" atau "Download PDF".
5 File PDF akan terdownload. Selesai! 🎉

🎯 Cara 2: Google Docs

1 Buka Google Docs
2 Buat dokumen baru.
3 Copy isi file panduan (dari Notepad), paste ke Google Docs.
4 Rapikan format jika perlu (judul, heading, bullet point).
5 Klik File → Download → PDF Document (.pdf).

🎯 Cara 3: Microsoft Word

1 Buka Microsoft Word.
2 Copy isi file panduan (dari Notepad), paste ke Word.
3 Rapikan format jika perlu.
4 Klik File → Save As → Pilih PDF.

🎯 Cara 4: Browser Print (Paling Cepat)

1 Buka file panduan dengan VS Code atau text editor apapun.
2 Klik File → Print atau tekan Ctrl+P.
3 Pilih printer "Microsoft Print to PDF" atau "Save as PDF".
4 Klik Print atau Save.
5 Pilih lokasi penyimpanan, beri nama file, klik Save. Selesai! 🎉
💡 Tips:
  • Gunakan Cara 1 (Online Converter) untuk hasil terbaik dengan format rapi
  • Gunakan Cara 4 (Browser Print) untuk cara tercepat
  • Pastikan semua gambar/icon sudah muncul sebelum convert
